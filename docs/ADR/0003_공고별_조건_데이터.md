# 공고별 조건 데이터

- 상태: 채택
- 날짜: 2026-09-12

## 결정

정책별 Java 클래스를 늘리는 대신 공고의 질문·선택지·판정표·근거·적용 기간을 JSON으로 저장한다. 판정표는 선택지 조합을 위에서부터 비교하고 첫 일치 결과를 사용한다. 어느 행에도 맞지 않으면 추가 확인으로 남긴다. 임의 수식이나 실행 코드는 받지 않는다.

PostgreSQL에 변경 불가 버전과 현재 적용 버전을 분리한다. 운영 명령이나 관리자 화면에서 파일로 초안을 등록하고, 원문 해시와 직전 적용 버전을 확인한 뒤 적용한다. 정책 수집과 같은 정책 행을 잠가 원문 변경과 적용이 엇갈리지 않게 한다. 관리자 화면의 쓰기는 조회한 개정도 확인하고, 요청 ID·작업자·사유를 규칙 변경과 같은 트랜잭션으로 기록한다. 같은 요청은 기존 결과를 반환해 응답 유실 후 중복 적용을 막는다. 원문 변경·기간 만료는 조회와 제출 시 즉시 차단한다. 적용 기간은 규칙을 사용할 기간이며 실제 접수 기간과 구분한다.

출생일 범위·만 나이 기준은 같은 데이터에서 기본 연령 비교와 질문 답변을 만든다. 만 나이는 기존 연령 모듈을 사용하고 미확인 병역 예외는 확인 대기로 남긴다. 월별 실적은 기준 월을 질문 범위와 답변 버전에 붙인다. 확인한 생년월일만 화면 메모리에서 재사용하고 다른 개인 조건은 임의 변환하지 않는다. 답변에는 정책 개정과 규칙 버전을 붙여 오래된 제출을 거부한다.

## 범위

현재 제공하는 11개 정책의 질문·판정을 데이터로 이전했다. 정책별 운영 클래스와 질문 분기는 제거하고 기존 구현을 고정된 비교 테스트 자료로 유지한다. 원문 충돌 안내와 검색용 모집 기간 보정은 별도 책임으로 남긴다. AI는 향후 같은 형식의 초안을 만들 수 있지만 이번 변경에 AI 공급자 연결이나 자동 승인은 포함하지 않는다. 공고 값의 변경에는 데이터 적용만 필요하고, 새로운 비교 방식에는 공통 비교 코드 변경이 필요하다.
