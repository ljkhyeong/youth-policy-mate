# 공고별 조건 데이터

- 상태: 채택
- 날짜: 2026-09-12

## 결정

정책별 Java 클래스를 늘리는 대신 공고의 질문·선택지·판정표·근거·적용 기간을 JSON으로 저장한다. 판정표는 선택지 조합을 위에서부터 비교하고 첫 일치 결과를 사용한다. 어느 행에도 맞지 않으면 추가 확인으로 남긴다. 임의 수식이나 실행 코드는 받지 않는다.

PostgreSQL에 변경 불가 버전과 현재 적용 버전을 분리한다. 운영 명령으로 초안을 등록하고, 원문 해시와 직전 적용 버전을 확인한 뒤 적용한다. 정책 수집과 같은 정책 행을 잠가 원문 변경과 적용이 엇갈리지 않게 한다. 원문 변경·기간 만료는 조회와 제출 시 즉시 차단한다. 적용 기간은 규칙을 사용할 기간이며 실제 접수 기간과 구분한다.

출생일 범위는 같은 데이터에서 기본 연령 비교와 질문 답변을 만든다. 확인한 생년월일만 화면 메모리에서 재사용하고 다른 개인 조건은 임의 변환하지 않는다. 답변에는 정책 개정과 규칙 버전을 붙여 오래된 제출을 거부한다.

## 범위

응시료 지원과 국가근로장학금을 먼저 이전한다. 기존 다른 정책의 질문은 유지한다. AI는 향후 같은 형식의 초안을 만들 수 있지만 이번 변경에 AI 공급자 연결이나 자동 승인은 포함하지 않는다. 공고 값의 변경에는 데이터 적용만 필요하고, 새로운 비교 방식에는 공통 비교 코드 변경이 필요하다.
