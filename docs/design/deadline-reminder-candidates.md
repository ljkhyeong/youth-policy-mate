# 마감 알림 후보 날짜

- 기준일: 2026-08-31
- 제품 기준: [PRD 7절](../PRD/0001_product-baseline/spec.md#7-관심-정책일정알림)
- 모집 정보: [모집 기간 설계](recruitment-period.md)
- 범위: 확인된 신청 마감의 D-7·D-3·D-1 후보 날짜만 계산한다. 저장·동의·예약·발송은 포함하지 않는다.

## 기준 날짜와 책임

정책 모듈이 확인된 모집 자료에서 서울 기준 마감 날짜를 제공한다. 날짜형은 원문의 종료 날짜를 그대로 사용하고, 시각형은 명시된 접수 종료 순간을 `Asia/Seoul`로 보았을 때의 날짜를 사용한다. 서울 자정에 끝나는 시각형도 그 순간의 날짜를 사용하며, 임의로 1초를 빼 전날로 바꾸지 않는다.

이 날짜는 일 단위 계산을 위한 값이다. 날짜형 마감을 정확한 자정·23:59 시각으로 바꾸지 않으며, 시각형의 시간대·종료 순간도 지우지 않는다. 결과는 기존 모집 자료·정책 개정·근거와 계산 시점을 함께 보존한다.

일정 모듈은 원문을 파싱하거나 모집 상태를 다시 계산하지 않는다. 기존 모집 상태 계산이 주입된 시계에서 한 번 읽은 시각과 서울 날짜를 그대로 사용한다. 전달된 모집 자료의 최신성·개정 선후 관계는 별도 호출 경계의 책임이다.

## 후보 계산

확인된 마감 날짜에서 7일·3일·1일을 각각 뺀다. 일수×24시간이나 영업일 계산이 아니며 주말·휴일을 다른 날짜로 옮기지 않는다. 날짜가 빠른 순서로 최대 세 개를 반환한다.

| 상황 | 반환하는 내용 |
|---|---|
| 미래 후보 날짜 | 후보 날짜와 D-7·D-3·D-1 구분. 발송 확정은 아님 |
| 오늘 후보 날짜 | 후보는 보존하되 발송 시각 확인 필요로 표시 |
| 지난 후보 날짜 | 제외. 오늘로 옮기거나 몰아서 발송할 후보로 만들지 않음 |
| 모든 후보 날짜가 지남 | 빈 목록과 남은 후보 날짜 없음 |
| 모집 마감 | 빈 목록과 모집 마감 사유 |
| 상시·소진 시 종료·마감 날짜 미확인 | 빈 목록과 확인된 마감 날짜 없음. 원래 모집 상태·이유는 보존 |

발송 시각이 정해지지 않았으므로 오늘의 후보가 이미 지난 발송인지, 아직 남은 발송인지는 판단하지 않는다. 미래 후보도 저장 상태·수신 동의·발송 시각 확인 전에는 예약으로 사용할 수 없다.

모집 시작 전이라도 확인된 마감 날짜가 있으면 후보를 계산한다. 시작일은 마감 알림 날짜를 다른 날로 옮기는 기준이 아니다. 이는 후보 산출 범위이며 모집 시작 전 실제 발송 여부를 확정한 것은 아니다.

## 후속 기능과 구분

마감 날짜·시각이나 적용 정책 개정이 바뀌면 새 모집 자료로 다시 계산한다. 계산 결과끼리 예약을 자동 취소·갱신하지 않는다. 상시·미확인으로 바뀌었을 때 과거 후보를 재사용하지 않는 동작은 확인하되, DB의 미발송 예약 취소는 예약 기능을 만들 때 구현한다.

회원 저장·해제, 이메일 활성화·해제, Outbox, 전송 재시도와 중복 방지, 발송 시각·만료 정책은 이번 모델 밖이다. 실제 발송을 연결하기 전 별도로 구현·검증해야 한다.

후보 계산 모델과 테스트를 구현했다. 실행 명령과 확인 범위는 [구현 기록](../development/deadline-reminder-candidates.md)에 정리한다.
