# AI 요청 실행 경계

## 1. 범위

[PRD 6.2·8절](../PRD/0001_product-baseline/spec.md), [AI 요청 전 판단](ai-request-admission.md), [예약·정산 상태](ai-budget-reservation-lifecycle.md)를 따른다. 예산 예약부터 외부 실행 결과의 내부 상태 반영까지 순서를 정의하되 특정 AI 공급자·모델·요금·응답 DTO는 정하지 않는다.

현재 요청에는 정책 개정·원본 해시·생성 방식·요청 순번이 있지만 AI에 보낼 원문 본문은 없다. 따라서 실제 프롬프트나 공급자 요청 형식을 만들지 않고 실행 신원과 분류한 결과만 포트로 전달한다. 사용자 생년월일·소득·연락처는 이 요청에 포함하지 않는다.

## 2. 실행 순서

1. 호출 측이 사전 판단의 `ReservationRequired`, 예약 식별자, 예약 시각과 호출 식별 정보를 준비한다.
2. `AiBudgetReservationStore`가 최신 예산을 잠그고 `HELD` 예약을 저장한다. 예약이 거절되면 실행 포트를 호출하지 않는다.
3. `AiBudgetReservationLifecycleStore`가 호출 식별 정보를 `DISPATCHED`로 기록한다.
4. 상태 저장 트랜잭션이 끝난 뒤 `PolicyAiExecutionPort`를 호출한다. 외부 응답을 기다리는 동안 DB 트랜잭션을 유지하지 않는다.
5. 결과 미확인은 `OUTCOME_UNKNOWN`으로 기록하고 예약액을 유지한다.
6. 응답을 받았지만 청구가 미확인이면 결과를 호출 측에 반환하고 예약은 `DISPATCHED`로 유지한다.
7. 확인된 실제 비용은 `SETTLED`, 확인된 무과금은 `RELEASED_NO_CHARGE`로 반영한다.

AI 응답 결과와 청구 확인은 별개의 사실이다. 후보를 받았다는 이유로 실제 비용을 0원이나 최대 예약액으로 추정하지 않는다.

## 3. 재전달과 불명확한 실패

- 같은 `HELD` 예약의 재전달은 호출 식별자를 처음 기록한 작업만 실행 포트를 호출한다.
- 이미 같은 호출 식별자가 저장된 `DISPATCHED` 재전달은 외부 실행을 반복하지 않는다. 호출 기록 직후 프로세스가 중단된 경우도 자동 재호출하지 않고 재시작 확인 대상으로 남긴다.
- 실행 포트가 타임아웃·연결 끊김을 확인한 경우에는 식별 가능한 `UncertainOutcome`을 반환해 `OUTCOME_UNKNOWN`으로 기록한다.
- 예상하지 못한 실행기 예외는 임의의 타임아웃이나 무과금으로 바꾸지 않는다. 예외를 전달하고 `DISPATCHED`와 예약액을 유지한다.
- 다른 요청의 응답이나 호출보다 빠른 응답·청구 시각은 적용하지 않는다. 기존 예약은 유지한다.

이 기준은 중복 외부 호출을 줄이지만 실행 소유권이나 정확히 한 번 호출을 보장하지 않는다.

## 4. 공급자 분리

`PolicyAiExecutionPort`는 공급자 DTO가 아니다. 실제 어댑터는 공급자 요청·응답을 다음 내부 결과로 분류해야 한다.

| 내부 결과 | 의미 | 예약 처리 |
|---|---|---|
| 응답·청구 대기 | AI 결과는 확인했지만 비용은 확인하지 못함 | 유지 |
| 응답·청구 확인 | AI 결과와 실제 비용을 확인함 | 정산 |
| 응답·무과금 확인 | AI 결과와 무과금 근거를 확인함 | 해제 |
| 결과 미확인 | 타임아웃·연결 끊김 등으로 결과를 확정하지 못함 | 유지 |

공급자 어댑터가 생기기 전까지 프로덕션 빈으로 등록하지 않는다. 인공 실행기는 통합 테스트에서만 사용한다.

## 5. 남은 연결

1. 공급자와 모델을 선정한 뒤 실제 정책 본문 취득·프롬프트·응답 검증 어댑터를 만든다.
2. AI 결과를 현재 정책 개정과 다시 비교하고 후보 본문·근거를 PostgreSQL에 저장한다.
3. 미완료 예약의 작업자 소유권, 호출 직전 중단, 재확인 시도 이력과 운영 조회를 설계한다.
4. 공급자 사용량·청구 조회로 청구 대기 예약을 정산하고 최대 비용 산정과 실제 청구를 대사한다.

현재 구현은 내부 순서와 금액 보존을 검증한 것이다. 실제 AI 품질·공급자 장애·외부 과금 상한이나 PRD AC-06·AC-11을 완료했다고 보고하지 않는다.
