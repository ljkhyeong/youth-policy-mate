# 웹앱 인터페이스 기준

2026-09-02 기준. 이 문서는 모바일을 우선하는 웹앱의 화면 구조와 표현 원칙을 정한다. 제품 기능과 완료 조건은 [PRD](../PRD/0001_product-baseline/spec.md), 현재 조건 입력의 구현 범위는 [비회원 조건 입력](../development/guest-conditions.md)을 따른다.

## 목표

- 사용자가 설명을 읽기 전에 지금 할 수 있는 한 가지 행동을 알 수 있게 한다.
- 작은 화면에서 한 손으로 주요 화면을 오갈 수 있게 한다.
- 실제 정책 데이터가 없는 상태를 가짜 추천이나 예시 정책으로 채우지 않는다.
- 로그인하지 않은 사용자가 입력값의 저장 여부를 행동 전에 알 수 있게 한다.

## 참고한 제품 패턴

2026-09-02 대한민국 App Store 공개 정보를 확인했다. 기능과 시각 표현을 복제하지 않고, 검증된 사용 흐름만 참고한다.

- [토스](https://apps.apple.com/kr/app/%ED%86%A0%EC%8A%A4/id839333328): 한 화면에서 주 행동 하나를 강하게 제시하고 복잡한 정보를 짧은 문장과 단계로 나누는 방식.
- [뱅크샐러드](https://apps.apple.com/kr/app/%EB%B1%85%ED%81%AC%EC%83%90%EB%9F%AC%EB%93%9C/id1195804784): 여러 기능보다 사용자의 현재 상태와 다음 행동을 홈에 우선 배치하는 방식.
- [웰로](https://apps.apple.com/kr/app/%EC%9B%B0%EB%A1%9C/id6444814937): 정책 서비스에서 최소 정보 입력 뒤 맞춤 정책과 마감을 이어서 관리하는 과업 구조. 같은 분야 참고 사례이며 평점이 높은 사례로 분류하지 않는다.

## 화면 구조

### 공통 탐색

- 데스크톱은 상단 앱 바에 `홈`, `정책 찾기`, `내 조건`을 둔다.
- 모바일은 하단 고정 탭에 같은 세 메뉴를 둔다. 브라우저 안전 영역을 포함해 콘텐츠와 겹치지 않게 한다.
- 현재 화면은 색상과 `aria-current`로 함께 표시한다.
- 앱 이름은 언제든 홈으로 돌아가는 링크다.

### 홈

- 첫 화면은 서비스 소개 페이지가 아니라 사용을 시작하는 앱 홈이다.
- 제목 다음에 생년월일·서울 자치구·취업상태 세 항목과 `내 조건 입력하기` 한 가지 주 버튼을 둔다.
- 개인정보가 서버로 전송되거나 저장되지 않는 현재 동작을 버튼 바로 아래에 표시한다.
- 정책 데이터 연결 상태와 현재 제공하지 않는 추천·저장·알림은 주 행동보다 낮은 위계로 안내한다.

### 조건 입력

- 입력과 확인을 한 열의 2단계 흐름으로 제공한다.
- 입력 항목은 레이블, 컨트롤, 짧은 도움말 순서로 배치한다.
- 기본 버튼은 화면 너비를 사용하고 초기화는 보조 텍스트 버튼으로 낮춘다.
- 확인 화면은 입력값만 요약하며 실제 자격이나 추천 결과처럼 보이는 내용을 만들지 않는다.

## 시각 기준

- 바탕은 옅은 회색, 주요 패널은 흰색, 기본 글자는 짙은 남색 계열을 사용한다.
- 대표 행동에만 파란색 `#246BFD`를 사용하고 성공·안전 안내는 녹색 계열로 분리한다.
- 본문 폭은 약 680px로 제한해 데스크톱에서도 모바일 과업의 집중도를 유지한다.
- 장식용 카드와 아이콘을 반복하지 않는다. 테두리·그림자·애니메이션은 정보 위계를 설명할 때만 사용한다.
- 운영체제 글꼴과 Pretendard·SUIT 대체 목록을 사용해 별도 웹 폰트 요청 없이 빠르게 표시한다.

## 현재 구현과 남은 범위

- `/`와 `/conditions`, 공통 셸·상태 화면 문구에 이 기준을 적용했다.
- 모바일 390px과 데스크톱 화면에서 홈, 입력, 확인 전환을 확인했다.
- 2026-09-05에 공개 정책 목록·검색·상세와 세 번째 탐색 메뉴를 추가했다. 저장·일정 메뉴는 해당 기능을 만들 때 추가한다.
- 설치형 PWA, 네이티브 앱 패키징, 오프라인 사용, 웹 푸시는 이 문서로 확정하지 않는다.

### 정책 목록·상세

- 목록에는 제목·설명 검색과 확인한 정책 수를 표시한다. 전체 수집 전에는 일부 정책을 제공한다는 안내와 온통청년 이동 경로를 둔다.
- 상세는 지원 내용·신청 안내를 읽고 공식 원문으로 이동하는 흐름으로 구성한다. 자격 비교 결과가 없다는 점, 출처·수집 시각을 표시한다.
- 연결 실패는 빈 결과와 구분하고 다시 불러오기를 제공한다. 상세 주소가 없으면 정책 목록으로 이동하는 404 안내를 제공한다.
