# AI학업장려 학자금대출 조건 질문

질문·판정은 [공고별 조건 데이터](policy-rule-data.md)로 관리한다. 2026-10-11에 정책 `20260903005400113371`(2026학년도 2학기 AI학업장려 학자금대출)에 **2026학년도 2학기 신청 조건** 질문과 기본 연령 비교를 연결했다. 규칙은 `V4__seed_employment_support_and_ai_study_loan_rules.sql`에 들어 있다. 다음 학기 공고는 새 정책 원문이므로 원문과 공식 안내를 다시 대조해 새 버전으로 등록한다.

## 공식 근거와 적용 범위

- 대조한 근거는 다음과 같다. 온통청년 수집 원문(2026-09-03 수정)과 함께 비교했다.
  - 「2026학년도 2학기 취업 후 상환 학자금대출의 자격요건 등에 관한 고시」(교육부고시 제2026-12호, 2026-07-01 시행) 제2조④
  - [한국장학재단 AI학업장려 학자금대출 신청대상](https://www.kosaf.go.kr/ko/tuition.do?pg=tuition19&ttab1=1)·대출일정·기타제도·자주하는 질문
  - 교육부 2026-05-28 보도자료, 한국장학재단 2026-09-21 보도자료(AI거점대학 전체 학과 확대)
- 검토한 내용 해시는 `1998a3b594bc6159b162f02d8286cb14d9f1642e83aeaf5bf395d2576b43aeed`, 규칙 버전은 `ai-study-loan-2026-2-v1`이다. 수집 원문의 신청기간(2026.07.01~11.17)에 맞춰 2026년 7월 1일부터 11월 17일까지(서울) 같은 원문에서만 질문을 제공한다. 신청 시작(7월 1일 9시) 전과 마감(11월 17일 18시) 뒤에는 질문 안내 문구를 바꾼다.
- 연령은 대출 신청일(본신청일) 기준이다. 기본 검색과 자동 입력은 오늘(서울 날짜) 신청을 가정한 만 나이를 쓴다.

| 질문 | 비교 기준과 예외 |
|---|---|
| 연령 | 대출 신청일 현재 만 35세 이하. 전문대학 계약학과(채용조건형)·선취업 후진학자·중소기업 재직자가 성인·평생교육 학위과정에 다니면 만 45세 이하다. 생년월일로는 만 35세까지만 채우고, 만 36세 이상은 예외를 확인할 때까지 추가 확인이다. |
| 국적 | 대한민국 국민. 해외이주 신고자·영주권자·재외국민과 외국인은 제외한다. |
| 대상학과 | AI·SW중심대학과 AI거점대학이 지정해 재단에 등록한 학과의 학부생(주전공 기준). 부산대·전남대·충남대는 전체 학과가 대상이다. 학과명으로 추정하지 않고 재단의 대상학과 조회로 확인하게 한다. 확인 전이면 추가 확인이다. |
| 학적 | 국내 대학 학부 재학생과 입학·복학 예정자. 대학원생·졸업유예자·학점은행제 학습자와 등록하지 않은 휴학생은 불충족이다. |
| 직전학기 이수학점 | 12학점 이상(성적 무관). 대학의 학기당 최소 이수학점이 12학점 미만이면 학사규정을 따른다. 신입·편입·재입학 후 첫 학기, 졸업학년, 장애인, 특별승인은 예외다. 12학점 미만이면서 예외가 없다고 답했을 때만 불충족이다. |

소득(학자금 지원구간)과 신용은 자격 기준이 아니어서 묻지 않는다. 대학 등록 확인 후 실행, 실행 마감(11월 18일 17시), 성실사용계획서·사용 결과보고서, 학자금 중복지원·등록금대출 미상환·부실자료 제출·금융거래 안심차단 같은 대출 제한은 결과의 남은 확인 사항으로 안내한다. 전체 자격은 추가 확인이다.

## 원문 차이와 한계

- 온통청년 원문은 대상을 "AI·SW분야 학부생"으로만 적었다. 실제 대상은 학교가 지정해 재단에 등록한 학과이며 학기마다 바뀐다. 2026-2학기 대상학과에는 심리학부·간호학과처럼 이름만으로는 AI·SW와 무관해 보이는 학과도 있어 학과명으로 판정하지 않는다.
- 원문은 이수학점 기준을 "성적기준"으로 적었다. 공식 안내는 성적 기준이 없고 이수학점 기준만 둔다. 국적·소득 무관·대학원생 제외는 원문에 없어 고시와 재단 안내를 따랐다.
- 온통청년 표기 연령은 만 19~35세지만 공식 기준은 "대출신청일 현재 만 35세 이하"이고 하한이 없다. 규칙은 하한을 두지 않아 만 18세 이하 학부생도 연령 충족이며, 상세의 온통청년 표기 조건과 다를 수 있다.
- 원문 수정(09-03) 뒤 9월 21일에 AI거점대학 3개교 전체 학과로 대상이 넓어졌다. 이 확대는 공식 보도자료를 따라 선택지에 넣었다.
- 졸업학년의 정확한 범위, 사이버대 제외 여부, 미등록 휴학 제한(재단 업무처리기준 안에서만 확인)은 공식 고시·안내에 명시돼 있지 않다. 미등록 휴학은 "대학 등록 확인 후 실행"이라는 재단 안내와 맞아 불충족으로 두었다.
- 사전신청자의 연령 기준일(7월 1일)은 사전신청이 끝나 반영하지 않았다.

## 연결과 검증

기존 질문 제공·답변 평가·목록 질문 필터·기본 연령 비교·생년월일 자동 입력에 그대로 연결된다. API 구조·생성 타입·웹 코드는 바꾸지 않았다. 이 공고의 수집 캡처(`src/test/resources/ontong/list-capture.json`)는 서버 테스트의 예시 정책으로 쓰인다. 담당자·등록기관 필드를 뺀 캡처라 내용 해시는 규칙과 다르지만, 규칙이 있는 번호를 검토 전 정책의 예시로 쓰지 않도록 `PolicyCatalogTest`는 번호만 바꾼 예시를 쓴다.
