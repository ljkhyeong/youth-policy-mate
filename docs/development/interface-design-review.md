2026-09-11 기준. 구현 커밋 `d4405c9`. 시각 기준은 [웹앱 인터페이스](../design/webapp-interface.md)를 따른다.

## 판단과 변경

청년 정책 서비스에는 지원 내용·접수 상태·조건 확인을 빠르게 읽는 구성이 적합하다. 기존 파란색과 밝은 배경, 한글 시스템 글꼴, 모바일 하단 탐색은 유지하고 정보 배치를 보완했다. 새 라이브러리·이미지·웹 폰트는 추가하지 않았다.

| 화면 | 확인한 문제 | 반영한 내용 |
|---|---|---|
| 홈 | 입력 항목을 큰 파란 패널에서 반복하고 정책 탐색 경로가 아래에 있음 | 검색·검색어 바로가기와 조건 입력을 함께 배치. 불필요한 숫자·시간 안내 제거 |
| 정책 목록 | 안내·필터가 길고 데스크톱에서도 한 열만 사용 | 검색어·접수 상태를 검색 버튼 하나로 적용. 넓은 화면은 두 열, 모바일은 한 열 |
| 정책 카드 | 상태 설명이 반복돼 내용 비교가 느림 | 접수 상태는 상단에 표시. 설명은 기본 `details`로 펼치며 원문 설명 유지 |
| 정책 상세 | 지원 내용 전에 저장·질문 기능을 거침 | 지원 내용·공식 안내를 먼저 표시하고 바로가기 제공. 원문 충돌·자격 미확인 안내 유지 |
| 공통 안내·조건 입력 | 아이콘 없는 로그인 안내가 24px 열에 갇힘. 입력 확인 제목이 고정 헤더에 가림 | 안내를 가변 폭으로 수정하고 초점 이동 대상에 스크롤 여백 적용 |

홈은 데스크톱에서 `[검색·탐색 | 조건 입력]`, 모바일에서 `[검색·탐색] → [조건 입력]` 순서다. 정책 조건 계산·API·인증·저장 동작은 변경하지 않았다.

## 검증

기준 변경 전 리비전은 `6f33f72`이며 아래 검증 이후 앱 변경은 커밋했다.

| `npm run verify -- check:web` | 린트·타입 검사 통과 | `.local/verification/1789132420815-e894f5a8.log` |
| `npm run verify -- build:web` | 프로덕션 빌드 통과 | `.local/verification/1789132472282-bb2932c2.log` |

테스트·타입 검사 후에는 CSS의 초점 스크롤 여백과 미사용 선택자만 수정했다. 해당 화면을 다시 확인하고 최종 CSS를 포함해 빌드했다. 서버 코드는 변경하지 않아 백엔드 검사를 반복하지 않았다.

Playwright로 다음을 확인했다.

- 홈·정책 목록·햇살론유스 상세·조건 입력·관리자 접근 안내·로그인 화면: 320·390·640·768·1280px에서 가로 넘침 없음. 390·1280px 화면을 촬영해 대표 배치를 확인했다.
- 홈 검색에서 실제 햇살론유스 정책으로 이동. 검색어·상시 접수·질문 필터 동시 유지. 결과 없음 안내 확인.
- `Enter`로 상태 설명 펼치기와 3px 초점 표시. 질문 바로가기의 초점 이동과 질문 5개 펼치기.
- 조건 입력·확인·초기화. 확인 제목의 상단 위치 약 100px, 공식 안내 링크 이동 후 약 90px로 고정 헤더 아래 노출.
- 로그인 제공자 미설정 안내가 정상 폭으로 표시됨. 관리자 화면은 비회원 접근 안내까지만 확인했으며 실제 관리자 데이터 화면을 새로 검증하지 않았다.

390px 목록의 첫 카드 시작 위치는 약 615px에서 479px로 줄었다. 화면·브라우저 로그는 `/tmp/youth-design-ui/`, 검증 요약은 `/tmp/youth-design-responsive.log`, `/tmp/youth-design-focus.log`에 있다. 검증용 입력은 초기화했고 전용 브라우저를 종료했다.

첫 촬영의 React 경고는 브라우저 촬영 도구가 하이드레이션 중 입력 커서 스타일을 바꿔 발생했다. 이후 로딩 완료와 `caret: "initial"`로 촬영해 재발하지 않았다. 기존 `/favicon.ico` 404는 이번 변경 범위에 포함하지 않았다.

로컬 웹 서버는 `npm run dev:web`로 실행 중이며 로그는 `/tmp/youth-design-web.log`다. 정책 서버는 검증된 기존 JAR와 로컬 PostgreSQL을 사용한다. 실제 로그인 제공자·이메일·배포 검증과 원격 반영은 이번 작업에 포함하지 않았다.

## 2026-10-05 화면 개편
