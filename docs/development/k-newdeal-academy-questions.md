# K-뉴딜 아카데미 조건 질문

질문·판정은 [공고별 조건 데이터](policy-rule-data.md)로 관리한다. 2026-10-05에 정책 `20260714005400113258`(k-뉴딜 아카데미)에 **2026년 공통 참여 조건** 질문과 기본 연령 비교를 연결했다. 규칙은 Flyway V33으로 배포하며 운영자가 이미 이 정책에 적용한 규칙이 있으면 바꾸지 않는다.

## 공식 근거와 적용 범위

- [고용24 K-뉴딜 아카데미 제도 안내](https://www.work24.go.kr/cm/c/f/1100/selecSystInfo.do?currentPageNo=1&recordCountPerPage=10&systId=SI00000512&systClId=SC00000391)(2026-07-22 수정)의 기본 요건·참여제한·참여 횟수 문구와 온통청년 수집 원문을 대조했다.
- 검토한 내용 해시는 `02369c6645f3cde944eb6186852b0a5c33c160e212ca6e0c01ccdd16e427f2b2`, 규칙 버전은 `k-newdeal-academy-2026-v1`이다. 수집 원문의 신청기간(2026.07.07~12.31)에 맞춰 2026년 7월 7일부터 연말까지(서울) 같은 원문에서만 질문을 제공한다. 원문·개정·규칙이 바뀌면 이전 답변을 거부한다.
- 연령은 참여 신청일 기준이다. 기본 검색과 자동 입력은 오늘(서울 날짜) 신청을 가정한 만 나이를 쓰고 실제 신청일에 다시 확인하도록 안내한다.

| 질문 | 비교 기준과 예외 |
|---|---|
| 연령 | 만 15~34세. 군필자는 의무복무 기간만큼 상한을 높여 최대 만 39세까지 적용한다. 만 35세 이상은 연장 여부를 확인할 때까지 추가 확인이다. |
| 취업 | 참여 신청일의 고용보험 피보험자격으로 확인한다. 주 30시간 미만 단시간·고용보험 가입 대상 플랫폼·일용 근로자가 훈련시간 외 근로를 증빙하거나 아카데미 개시 전 해소하면 예외다. |
| 사업자등록 | 등록이 없어야 한다. 실제 사업을 영위하지 않음을 객관적으로 증명하거나 개시 전 해소하면 예외다. |
| 재학 | 고등학교·대학(원) 재학생은 제한한다. 대학(원) 졸업예정(4학년 2학기 이상·마지막 학기), 졸업 이수학점 모두 취득, 휴학, 고등학교(특성화고·산업수요맞춤형고·일반고) 직업교육 관련 학과 3학년 2학기의 학교장 추천 졸업예정자는 예외다. |

고용24 참여제한 머리말의 "신청일 현재 기준으로 판단하며, 프로그램 개시일 전까지 참여 제한 사유가 해소되는 경우 참여 가능(증빙 필요)"은 모든 참여제한에 적용한다. 취업·사업자등록은 "해소 인정 확인"을 충족으로, 재학·직업훈련의 "시작 전 해소 예정"은 증빙 확인 전까지 추가 확인으로 둔다. 불충족 선택지는 시작 전에도 해소되지 않는 경우로 한정한다. 예외는 "인정 확인" 선택지로만 충족 처리하고, 확인 중이면 추가 확인으로 남긴다. 구직등록(직업안정기관 등록, 시작 전까지 등록·증빙 가능), 대한민국 국적, 같은 아카데미 재참여 금지, 아카데미별 선발·참여수당 요건은 결과의 남은 확인 사항으로 안내한다. 구직등록은 신청 전에 할 수 있는 절차라 질문으로 불충족 처리하지 않는다. 전체 자격은 추가 확인이다.

## 원문 차이와 한계

- 휴학 예외 범위가 안내마다 다르다. 고용24는 "졸업예정자가 아니더라도 신청일 현재 휴학 중인 자", 수집 원문은 "신청일 현재 휴학 중으로 및 장기 휴학생(연속 1년 이상 또는 통산 2년 이상 휴학 중인 자)임을 증명한 경우"다. 수집 원문은 두 조건을 잇는 부분이 깨져 있어 둘 다 요구하는지 모호하다. 두 안내 모두 인정하는 장기 휴학만 충족으로 보고 1년 미만 휴학은 추가 확인으로 남긴다.
- 수집 원문의 연령 안내는 기준일·예외를 적지 않았다. 신청일 기준과 군복무 연장은 고용24 안내를 따른다.
- 만 나이 연결은 상한이 하나라서 계산한 만 나이가 34세를 넘으면 "군복무 연장 확인 중"으로 연결한다. 그래서 만 40세 이상도 기본 비교에서는 불충족이 아니라 추가 확인으로 나온다. 결과 설명에 만 40세 이상은 참여할 수 없음을 적었고 질문에서 직접 답하면 불충족으로 판정한다.
- 고등학교 직업교육 학과 학교장 추천, 졸업 이수학점 예외와 모든 제한의 개시 전 해소는 고용24 안내에만 있다(수집 원문은 개시 전 해소를 취업·사업자등록 아래에만 적음). 수집 원문과 충돌하지 않아 반영했다.

## 연결과 검증

V33 규칙은 기존 질문 제공·답변 평가·목록 질문 필터·기본 연령 비교·생년월일 자동 입력에 그대로 연결된다. API 구조·생성 타입·웹 코드는 바꾸지 않았다. 테스트 고정 자료(`PolicyRuleFixtures`)가 V33을 읽는다.

- 변경 검토에서 개시 전 해소 단서가 모든 참여제한에 걸리는 점, 참여 횟수의 기준 연도, 연령 연장 선택지 문구, 직업교육 예외의 고등학교 한정, 수집 원문 인용을 찾아 고쳤다.
- 로컬 DB에 V33을 적용한 검증용 서버(8180)와 운영 모드 웹(3103)으로 헤드리스 확인했다. 질문 있는 정책 목록이 12건이고, 상세에서 질문 6개가 표시되며 320·1280px에서 가로 넘침과 콘솔 오류가 없었다. 1년 미만 휴학과 시작 전 종료 예정 직업훈련은 추가 확인, 나머지 충족 답변은 충족으로 표시됐고 구직등록·국적 등 남은 확인과 공식 안내가 나왔다.
- 기본 조건 비교에서 1995-03-01 출생은 연령 충족, 1990-03-01 출생은 군복무 연장 안내와 함께 추가 확인이었다.
- 검토 중 V33 내용을 고치면서 로컬 DB에 먼저 적용된 V33의 규칙·적용 버전·Flyway 기록 행만 지우고 다시 적용했다. 다른 정책·회원 데이터는 바꾸지 않았다.
- 운영 DB의 원문 해시가 로컬과 같은지는 확인하지 못했다. 다르면 규칙은 적용되지 않고 관리자 조건 검토에 재검토 대상으로 표시된다.
