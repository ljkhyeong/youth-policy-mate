# 2026년 상반기 중개보수·이사비 지원 질문

## 원문과 적용 범위

2026-09-06에 서울시 공고 제2026-1109호를 확인했다.

- [서울시 상반기 모집 공지](https://youth.seoul.go.kr/bbs/view.do?key=2303300002&pstSn=2604010002)
- [공고 PDF](https://soco.seoul.go.kr/coHouse/cmmn/file/fileDown.do?atchFileId=12817e11dea24565ae8f7a84b98175db&fileSn=1): 1쪽 접수 기간, 2쪽 주소·연령·소득, 3쪽 주택·참여 제한·지원 비용, 4쪽 선발 기준

온통청년 정책 `20260614005400213232`의 현재 저장 원문 해시 `e3f828c1c37c1ecddde5a2dc59065e1179642d0fd7be3e919ec8cb9b07441c42`에만 연결한다. 이 원문의 신청 기간은 2026.4.1.~4.14.이며, 동일 제목의 다른 정책번호나 갱신된 하반기 안내로 확대하지 않는다. 규칙 버전은 `moving-fee-2026-h1-v1`이다.

## 질문과 남은 확인

질문은 공고의 출생일 범위, 이사·전입신고 기간, 세대주·임차인·주민등록, 본인 무주택, 주택 거래금액 다섯 항목이다. 공고에 적힌 날짜와 양 끝 경계를 사용한다. 현재 서울 거주를 과거 신청 당시 전입 완료로 바꾸지 않는다.

무주택 판단에는 분양권·입주권·공유지분이 포함되며, 전세사기 피해 주택 취득 등 예외가 확인 중이면 미확인으로 남긴다. 청약의 무주택 기준을 가져오지 않는다. 주택 거래금액은 보증금과 월세를 기준으로 하며 사용자가 확인한 범위를 답한다.

다섯 항목을 모두 충족해도 소득·보험료·가구원, 중복지원, 부모 주택 임차, 급여 수급·국적 관련 제한, 실제 지출·증빙·선정은 추가 확인이 필요하다. 다른 기관에서 비용 한 종류를 지원받은 사람에게 다른 비용 지원이 가능한 예외를 안내한다. 최종 자격을 신청 가능으로 표시하지 않는다.

접수는 서울 시각 2026.4.1. 10:00~4.14. 18:00이다. 질문과 평가 결과에 접수 전·마감을 표시하되 조건 충족 여부와 분리한다. 검토한 연도가 끝나거나 원문·개정·규칙이 바뀌면 이전 답변의 평가를 중단한다.

검증 결과는 [개인 조건 탐색](condition-policy-discovery.md#검증)에 기록한다.
