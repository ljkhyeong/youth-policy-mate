# 2026년 상반기 중개보수·이사비 지원 질문

- [서울시 상반기 모집 공지](https://youth.seoul.go.kr/bbs/view.do?key=2303300002&pstSn=2604010002)
- [공고 PDF](https://soco.seoul.go.kr/coHouse/cmmn/file/fileDown.do?atchFileId=12817e11dea24565ae8f7a84b98175db&fileSn=1): 1쪽 접수 기간, 2쪽 주소·연령·소득, 3쪽 주택·참여 제한·지원 비용, 4쪽 선발 기준

온통청년 정책 `20260614005400213232`의 현재 저장 원문 해시 `e3f828c1c37c1ecddde5a2dc59065e1179642d0fd7be3e919ec8cb9b07441c42`에만 연결한다. 이 원문의 신청 기간은 2026.4.1.~4.14.이며, 동일 제목의 다른 정책번호나 갱신된 하반기 안내로 확대하지 않는다. 규칙 버전은 `moving-fee-2026-h1-v4`이다. 이전 `v1`·`v2`·`v3` 답변은 HTTP 409로 차단하며 기존 화면이 답변을 지우고 최신 질문을 다시 받는다.

## 질문과 남은 확인

질문은 공고의 출생일 범위, 이사·전입신고 기간, 세대주·임차인·주민등록, 본인 무주택, 주택 거래금액, 건강보험료 기준 소득, 중복지원과 참여 제한을 확인한다. 중복지원은 서울시 사업 수혜 여부·타 기관 지원 항목·확인할 신청 비용을 따로 묻고 하나의 비교 결과로 제공한다. 공고에 적힌 날짜와 양 끝 경계를 사용한다. 현재 서울 거주를 과거 신청 당시 전입 완료로 바꾸지 않는다.

무주택 판단에는 분양권·입주권·공유지분이 포함되며, 전세사기 피해 주택 취득 등 예외가 확인 중이면 미확인으로 남긴다. 청약의 무주택 기준을 가져오지 않는다. 주택 거래금액은 보증금과 월세를 기준으로 하며 사용자가 확인한 범위를 답한다.

소득은 2026년 3월 건강보험료 고지금액을 공고 2쪽의 가구원 수·가입 유형별 중위소득 150% 기준표와 비교한 답변을 받는다. 기준 이하(같은 금액 포함)는 충족, 초과는 불충족이다. 장기요양보험료는 제외하며 피부양자는 주소가 분리되어도 부양자의 고지금액을 사용한다. 부양자 보험료·가구원 수·가입 유형이 확인 중이거나 보험료 조회가 어려워 대체 증빙을 확인하는 경우는 미확인으로 남기고 각각의 확인 사유를 표시한다. 월급·취업 상태를 보험료로 환산하거나 피부양자의 본인 보험료를 0원으로 판정하지 않는다. 보험료 금액·가구원 정보·서류 자체를 수집하지 않는다.

중복지원은 신청 전 이력을 사용한다. 서울시 이 사업은 생애 1회이며 자치구·중앙부처·LH·SH 등 타 기관 지원과 구분한다. 타 기관 이력은 2022.1.1. 이후 서울 전입·서울 내 이사에 대한 지원을 확인한다. 기관이나 항목이 불명확하거나 생필품비 등 비용 구분이 필요하면 기관 확인으로 남긴다.

| 확인한 지원 이력 | 확인할 비용 | 중복지원 결과 |
|---|---|---|
| 서울시 이 사업 수혜 | 어느 비용이든 | 불충족: 생애 1회 제한 |
| 서울시 미수혜, 타 기관 중개보수만 | 이사비만 | 충족: 다른 비용 예외 |
| 서울시 미수혜, 타 기관 이사비만 | 중개보수만 | 충족: 다른 비용 예외 |
| 서울시 미수혜, 타 기관 한 종류 | 이미 지원받은 비용만 | 불충족, 다른 비용 확인 안내 |
| 서울시 미수혜, 타 기관 한 종류 | 두 비용 모두 | 추가 확인, 중복 항목을 제외해 재확인 |
| 타 기관 두 비용 모두 | 어느 비용이든 | 불충족 |
| 서울시·타 기관 모두 미수혜 | 어느 비용이든 | 충족, 인정 비용은 별도 확인 |

필요한 지원 이력이나 비용 구분이 미확인이면 추가 확인으로 남긴다. 다만 이미 확인한 서울시 수혜나 타 기관 두 비용 수혜 제한은 다른 답변이 없어도 유지한다. 확인된 수혜 이력이 전혀 없다면 신청 비용 미선택은 중복지원 결과를 바꾸지 않는다. 이 예외는 소득·무주택 등 다른 조건을 면제하지 않는다.

참여 제한은 신청 당시 부모 소유 주택 임차, 생계·의료·주거급여 수급, 외국인·재외국민 해당 여부를 각각 확인한다. 부모와 동거한다는 이유로 부모 주택 임차를 추정하지 않으며 교육급여만 받는 경우를 위 세 급여 수급으로 분류하지 않는다. 미응답·미확인은 각 항목의 추가 확인으로 남긴다. 주택 소유·중복지원의 예외가 참여 제한을 면제하지 않는다.

선택한 비용에 따라 지출 기간(2024.1.1.~2026.4.14.)과 인정·제외 비용을 안내한다. 중개보수는 임대차계약 체결 비용이며 재계약·중도 퇴실 비용을 제외한다. 이사비는 개인용달·(반)포장이사·사다리차 이용비 등을 안내하고 청소·택배·대중교통·택시·렌터카 비용을 제외한다. 두 비용을 선택하면 두 안내를, 미선택이면 비용 선택 안내를 표시한다. 지급액이나 증빙의 적격 여부는 계산하지 않는다.

모든 질문을 충족해도 소득·수혜 이력·참여 제한의 증빙 인정, 기타 사업 취지에 따른 제한, 실제 지출·선정은 기관 확인이 필요하다. 최종 자격을 신청 가능으로 표시하지 않는다.

접수는 서울 시각 2026.4.1. 10:00~4.14. 18:00이다. 질문과 평가 결과에 접수 전·마감을 표시하되 조건 충족 여부와 분리한다. 검토한 연도가 끝나거나 원문·개정·규칙이 바뀌면 이전 답변의 평가를 중단한다.

## 검증

코드 리비전 `c6550ac`에서 아래 검증을 통과했다. 이후 변경은 문서뿐이다.

| 실행 | 확인 범위·결과 | 로컬 로그 |
|---|---|---|
| `npm run generate:api` | 서버 DTO에서 OpenAPI·TypeScript 재생성. 답변 상한 변경 외 계약 차이 없음 | `/tmp/youth-moving-restrictions-api.log` |
| `npm run verify -- test:policy-catalog -- --tests 'kr.youthpolicymate.policy.catalog.*RulesTest'` | 정책 규칙·PostgreSQL API 검사 통과. 참여 제한별 충족·불충족·미확인, 기존 조건 유지, 비용별 안내, 12개 답변 제출·이전 버전 409 차단 확인 | `.local/verification/1788830089609-06b6b677.log` |
| `npm run verify -- check:api-types` | 생성 타입 일치 확인 | `.local/verification/1788830091766-47f9edd2.log` |
| `npm run verify -- check:web` | 웹 린트·타입 검사 통과 | `.local/verification/1788830093097-32a7307a.log` |
| `npm run verify -- package:backend` | 서버 실행 파일 생성. 테스트 반복 없음 | `.local/verification/1788830140911-ebb632f9.log` |

실제 로컬 정책에서 12개 답변을 제출해 조건 충족 결과를 확인했다. 부모 소유 주택 답변을 바꾸면 해당 항목이 불충족으로 바뀌고, 신청 비용을 중개보수에서 이사비로 바꾸면 제외 비용 안내도 바뀌었다. 최종 자격은 추가 확인을 유지했다. PC 입력과 키보드 Enter 제출, 375px 모바일의 새 질문 줄바꿈·선택지·가로 넘침 없음을 확인했다. 검증용 답변을 지우고 임시 브라우저를 종료했다. 개발 화면의 기존 `/favicon.ico` 404 외에 질문 요청 실패는 없었다.

전체 질문 제출을 위해 `PolicyQuestions.Request.answers`의 상한을 10개에서 20개로 늘렸다. 실제 명세의 `maxItems`도 20이며 생성 TypeScript의 형태는 같다. 등록하지 않은 질문·중복 답변 검증은 유지한다. 웹 소스·DB 스키마는 바꾸지 않아 웹 빌드·전체 서버 검사는 반복하지 않았다. 기본 연령 비교는 기존 규칙을 그대로 사용하며 이전 기록은 [개인 조건 탐색](condition-policy-discovery.md#검증)에 있다. 로컬 서버는 새 실행 파일로 반영했으며 로그는 `/tmp/youth-moving-restrictions-backend.log`다. 정기 수집·이메일·알림 실행은 비활성화했다.
