# 온통청년 표기 조건 참고 표시

2026-10-05 구현. 질문 규칙을 정책마다 검토하기 전에도 모든 정책에서 온통청년 API의 구조화 조건을 볼 수 있게 했다. 기준은 [PRD 3.2·5.2](../PRD/0001_product-baseline/spec.md), 계약은 [조회 문서](policy-catalog.md#공개-계약과-화면), 값 관찰은 [API 조사](../research/ontong-api-contract.md#구조화-조건-표기-관찰)를 따른다.

## 표시 원칙

- 판정이 아니라 출처를 밝힌 참고 정보다. 결과는 계속 추가 확인이며 연령 충족 우선 정렬에 쓰지 않는다. 검토한 공고별 규칙이 있으면 그 결과가 우선한다.
- 제한을 표기한 값만 보여준다. 연령 제한 여부 `Y`, 소득 `무관`, 취업·학력 `제한없음`은 조건이 없다는 근거가 아니어서 숨긴다(국가근로장학금은 소득 `무관` 표기지만 실제 소득 기준이 있다).
- `기타`나 의미를 확인하지 못한 코드가 섞이면 대상을 좁혀 보이지 않게 "등 · 공식 안내 확인"을 붙인다.
- 저장된 표시 내용(`PolicyContent`)과 해시를 바꾸지 않고 조회 시점에 현재 개정 원본에서 계산한다. 기존 질문 규칙의 원문 해시에 영향이 없다.

| 위치 | 표시 |
|---|---|
| 정책 상세 | 본문 첫 칸 "온통청년 표기 조건"에 연령·소득·취업 상태·학력. 공고 원문과 다를 수 있고 없는 조건이 있을 수 있다는 안내. 표기가 없으면 칸을 숨긴다. |
| 내 조건 결과 | 검토된 연령 비교가 없으면 연령 항목에 표기 범위와 오늘(서울) 기준 만 나이, 카드 요약에 같은 내용. 취업·학력·소득 항목에 나머지 표기. |

로컬 정책 40건 기준으로 검토된 연령 비교 10건 외에 16건이 표기 연령 범위를 새로 보여준다. 나머지 14건은 API에 제한 표기가 없다.

## 검증

| 명령 | 결과 | 로그 |
|---|---|---|
| `npm run verify -- test:policy-catalog -- --tests '...PolicySourceConditionsTest'` | 통과(표기 해석, 상세 응답, 카드 요약·연령 항목, 서울 자정 만 나이, 생년월일 미입력, 검토 규칙 우선, 제한 없음 숨김) | `.local/verification/1791180703836-445bc223.log` |
| `npm run verify -- check:backend` | 서버 전체 테스트·빌드 통과(실패·건너뜀 없음). 생성 계약 일치 | `.local/verification/1791180882745-71b7fb6b.log` |
| `npm run verify -- test:web` / `check:web` / `build:web` | 통과(상세 표기 칸 표시·숨김) | `.local/verification/1791180540498-cec79578.log` 외 |

- 변경 검토에서 기타가 섞인 취업 대상 축소, 생년월일 미입력 시 안내 누락, 학력 문구 중복, 없는 조건 안내, 문서 누락을 찾아 고쳤다. 판정·정렬 미사용과 해시 무영향은 검토로 확인했다.
- 로컬 DB와 검증용 서버(8180)·운영 모드 웹(3103)으로 헤드리스 확인했다. 청년예술인 상세에 "만 18~39세·연소득 3,692만 원 이하"가 나오고 K-패스는 칸을 숨겼다. 320·1280px에서 가로 넘침과 콘솔 오류가 없었다. 내 조건에서 1995-03-01을 반영하면 미검토 정책 카드 요약에 표기 범위와 만 31세가 나왔다.
- 학력 코드 `0049004`·`0049007`의 의미는 코드 정의서 전체를 확인하지 못해 공식 안내 확인으로 둔다. 코드표를 확인하면 이름 대응을 추가한다.
