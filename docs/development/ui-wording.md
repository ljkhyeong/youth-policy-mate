# 화면 문구 정리

2026-09-05에 홈·정책 목록과 상세·조건 입력·정책별 질문·로그인·내 정책·이메일 안내를 수정했다. 문구 기준은 [PRD 3.4](../PRD/0001_product-baseline/spec.md#34-화면-문구)를 따른다.

## 변경 내용

- 목록 표시는 ‘조건 확인 질문 있음’, 질문 시작은 ‘질문에 답하기’로 통일했다. 상세로 이동하는 ‘지원 내용·저장하기’는 ‘지원 내용 보기’로 바꿨다.
- 결과는 ‘확인한 조건 충족’, ‘충족하지 않은 조건 있음’, ‘추가 확인 필요’로 표시한다. 공식 심사 결과가 아니라는 안내는 결과 상단에 한 번 표시하고, 항목별로는 사유와 다음 행동을 안내한다.
- 응시료·국가근로장학금·K-패스의 안내를 짧게 정리했다. 학자금 지원구간 등 공식 용어, 출생일 기준, 적용 연도·학기·월, 예외와 최종 자격의 추가 확인은 유지한다.
- 이메일 인증과 수신 동의를 구분했다. 인증 메일 재요청에 따른 이전 코드 무효·동의 해제, 주소 삭제에 따른 대기 알림 취소를 구체적으로 안내한다. 발송 여부가 확인되지 않은 상태를 발송 완료로 표시하지 않는다.
- 마감일이 없는 경우 원천 기간 코드에 따라 상시 접수·접수 종료·미확인 사유를 구분한다. 마감 날짜와 예약 계산은 기존대로 유지한다.

## 검증

- 웹 테스트 66건, 정책 관련 서버 테스트 36건 통과. 서버 테스트에는 마감 안내의 사유 구분 1건을 추가했다. 공통 심사 안내를 결과 상단으로 옮긴 부분도 기존 화면 테스트에서 확인했다.
- 린트·타입 검사·생성 타입 일치·웹 Webpack 빌드·서버 실행 파일 빌드 통과.
- 실제 로컬 브라우저에서 질문 필터 3건, 키보드로 필터·질문 이동과 시작, K-패스의 충족·불충족·추가 확인 문구와 최종 자격 안내를 확인했다.
- 모바일 390px·데스크톱 1280px에서 질문과 이메일 화면의 가로 넘침이 없고 문구가 표시되는지 확인했다.
- 이메일 인증·수신 동의·재요청·주소 삭제 화면은 브라우저 시험 응답으로 확인했다. 시험 응답을 제거했으며 실제 로그인과 외부 메일 수신은 이번 검증에 포함하지 않았다.

API 필드·자격 규칙·DB 스키마와 수집 원본은 변경하지 않았다. 로컬 웹과 서버에는 새 빌드를 반영했다.
