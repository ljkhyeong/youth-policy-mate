# 청년주택드림청약통장 가입 질문

2026-09-05 구현. 네 번째 실제 정책에 조건 확인 질문을 추가했다. [PRD 5절](../PRD/0001_product-baseline/spec.md#5-자격-안내와-추천-근거)에 따라 가입 조건과 금리·세제·대출 심사를 구분한다.

## 대상과 공식 근거

- 정책번호 `20260616005400113238`, 제목 `청년주택드림청약통장`, 로컬 개정 `1`.
- 검토한 내용 해시: `52ab8f797a2bd470745ded339b0b789ea6baf46e44177f4699e6d60fffc8d214`.
- 규칙 버전: `youth-housing-2026-v1`. 질문의 소득 기준 연도는 2026년 가입 기준이다.
- [KB국민은행 상품 안내](https://obank.kbstar.com/quics?cc=b061761%3Ab061770&isNew=N&page=C020702&prcode=DP01000935)의 가입·전환 대상과 구비서류를 확인했다. 직전 과세연도, 소득 미확정 시 전전 연도, 첫 취업자의 연환산 서류, 병역기간 차감과 군복무자 소득 예외를 근거로 사용했다.
- [우리은행 상품 안내](https://spib.wooribank.com/pib/Dream?PRD_CD=P010002293&PRD_YN=Y&cc=c007095%3Ac009166%3Bc012263%3Ac012399&withyou=PSDEP0013)에서 만 19~34세·본인 무주택·연소득 5천만 원 이하 또는 군복무자라는 기본 가입 대상을 교차 확인했다.

확인일은 2026-09-05다. 온통청년에서 연결한 주택도시기금 페이지는 응답 시간 초과, 국토교통부 소개 페이지는 반복 이동으로 본문을 읽지 못했다. 따라서 현재 취급 은행의 공식 상품 안내를 사용했다. 수집 원본은 수정하지 않았다.

## 질문과 비교 범위

| 질문 | 처리 기준 |
|---|---|
| 가입일 연령 | 만 19~34세 또는 은행에서 인정 병역기간 차감 후 만 34세 이하로 확인한 경우 충족. 만 19세 미만, 차감 대상이 아니거나 차감 후에도 만 35세 이상이면 불충족. 병역기간 확인 중은 추가 확인. |
| 본인 무주택 | 가입일에 본인 소유 주택이 없으면 충족, 있으면 불충족. 소유 여부가 불분명하면 추가 확인. 세대원의 무주택이나 세대주 요건을 가입 기준으로 추가하지 않는다. |
| 소득서류 기준 | 2025년 신고소득 서류, 은행에서 확인한 2024년 적용·첫 취업 연환산·군복무자 예외를 구분한다. 미확인 기준으로 금액만 비교하지 않는다. |
| 소득 금액 | 확인된 총급여액·종합소득금액이 연 5,000만 원 이하인지 비교한다. 월급·매출·가구소득을 대신 사용하지 않는다. 군복무자 예외와 비과세 소득만 있다는 답변이 모두 있어야 소득 예외를 적용한다. |

소득 관련 두 답변은 하나의 결과 항목에서 함께 표시한다. 군복무자 예외를 선택했지만 과세 소득 금액도 선택한 경우, 일반 소득 기준을 선택했지만 비과세 소득만 있다고 답한 경우는 추가 확인이다. 소득 미응답을 0원으로 취급하지 않는다. 병역기간·복무 유형·증빙서류·신규 취업자의 연환산 금액을 서비스에서 계산하거나 검증하지 않는다.

군복무자 소득 예외는 복무 중인 대상자 또는 해당 과세연도에 복무한 전역자 등 공식 범위의 확인이 필요하다. 단순 군필 여부로 소득 예외를 적용하지 않는다. 연령 차감과 소득 예외는 독립된 항목이며 주택 보유 등 다른 조건을 면제하지 않는다.

세 결과 항목의 충족·불충족·추가 확인과 별도로, 전체 `status`는 계속 `NEEDS_REVIEW`다. 국내 거주자 여부·증빙, 기존 청약 계좌의 신규 가입·전환, 우대금리·비과세·소득공제, 청약 자격과 연계 대출은 은행의 추가 확인 사항이다. 생년월일·소득 금액·계좌번호·증빙을 수집하거나 답변을 저장하지 않는다.

## 기존 화면 연결과 기준 변경

`YouthHousingSavingsRules`를 `ReviewedPolicyQuestions`와 `PolicyQuestionService`에 등록했다. 기존 질문·결과 API와 화면으로 제공하며 목록 표시·질문 필터에도 함께 반영한다. API 구조·생성 타입·프런트엔드 소스·DB 스키마는 바꾸지 않았다.

원문 내용 해시·개정·규칙이 다르면 이전 제출을 409 `POLICY_CHANGED`로 거절한다. 한 요청은 같은 시각으로 비교하며 서울 기준 2027년부터 질문과 필터에서 제외한다. 이는 소득 기준 연도의 재검토를 위한 제한이다. KB국민은행이 안내한 가입 가능 기한은 2028-12-31이며, 서비스에서 2026년 말로 사업 종료일을 정한 것이 아니다.

은행의 공식 안내를 자동 감시하지는 않는다. 온통청년 원문에 반영되기 전 은행 기준이 바뀌면 별도 검토가 필요하다.

## 검증과 로컬 반영

- 새 규칙 검사 6건과 PostgreSQL API 검사 2건을 추가했다. 소득 증빙 기준·군복무 예외·미응답, 개정·규칙·원문 변경과 서울 연말을 확인했다.
- 정책 관련 서버 44건, 서버 전체 **440건**과 빌드 통과. 실패·오류·건너뜀 0. 실제 생성 OpenAPI와 저장 계약의 일치 검사도 통과했다.
- 모바일에서 잘리던 선택지를 줄이고 연령 초과 답변을 나눈 뒤 정책 관련 44건과 로컬 실행 파일 빌드를 다시 확인했다.
- API 구조와 웹 소스 변경이 없어 웹 테스트·빌드는 재실행하지 않았다.
- 실제 브라우저에서 목록의 질문 필터 4건과 상세 이동, 미응답·충족·주택 보유·소득 미확인·군복무 예외와 답변 불일치를 확인했다. 수정 시 결과 삭제, 답변 지우기, 새로고침 초기화도 확인했다.
- 모바일 390px와 데스크톱 1280px에서 선택지·결과·가로 넘침을 확인했다. 링크·질문 시작·제출의 Enter 동작과 결과 제목 초점을 확인했다. 기본 선택상자의 키보드 답변 선택 전체 흐름은 이번 검증에 포함하지 않았다.
- 새 로컬 서버의 정상 상태와 정책 40건 중 질문 제공 4건을 확인했다. 외부 로그인·SMTP·수집 주기·실제 `.env`는 변경하지 않았다.
- 전체 검사 종료 시 기존 Spring Session 정리 작업의 DB 연결 중단 경고가 재현됐다. JUnit 실패는 없으며 종료 순서는 이번 변경에 포함하지 않았다.
