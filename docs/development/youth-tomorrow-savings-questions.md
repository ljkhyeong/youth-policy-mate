# 청년내일저축계좌 신규 가입 질문

2026-09-08 구현, 코드 `9bda935`. 정책 `20260430005400113009`의 검토한 내용에 2026년 5월 신규 가입 질문을 제공한다. 기존 가입자의 유지·지원금 지급을 판단하는 기능은 아니다.

## 확인 근거와 범위

- [복지로 2026년 모집 공고](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/customer/notice/1309680_1141.html): 2026.5.4.~5.20. 모집과 신규 가입의 소득 기준.
- [2026년 자산형성지원 통장사업 지침](https://hope.welfareinfo.or.kr/pds/GuideLine.pdf): 인쇄 쪽수 5~6쪽의 참여 이력, 11~12쪽의 제외 대상·중복참여, 61~63쪽의 연령·근로·소득과 증빙. 2026-09-08 확인했다.
- [하남시의 같은 모집 안내](https://www.hanam.go.kr/www/contents.do?key=12492): 지침의 신청 월 연령 기준을 적용한 출생일 범위와 세전 소득 기준을 대조했다.
- [보건복지부 모집 설명](https://www.korea.kr/news/policyNewsView.do?newsId=148963836): 신규 가입 대상 축소와 가입 후 근로·저축·교육·서류 제출 조건을 구분했다.

수집 안내에는 가구소득 100%·50%가 섞여 있고, 최저 연령도 ‘신청 전월’ 기준으로 적혀 있다. 모집 공고와 지침의 기준으로 질문을 제공하면서 소득·출생일 차이 두 가지를 [원문 충돌 안내](policy-source-notices.md)에 표시한다. 수집 본문·개정·DB 데이터는 바꾸지 않는다.

| 질문 | 비교 기준 |
|---|---|
| 출생일 범위 | 1986.5.1.~2011.5.31., 양 끝 날짜 포함. 오늘의 만 나이를 사용하지 않는다. |
| 소득활동·월 소득 | 질문 두 개를 한 항목으로 비교한다. 인정되는 활동과 본인 세전 근로·사업소득 월 10만 원 이상을 함께 확인한다. |
| 가구 소득인정액 | 신청 당시 가구 범위와 소득·재산을 반영해 확인한 중위소득 50% 이하 기준. 월급·건강보험료·가입 후 유지 기준으로 대신하지 않는다. |
| 중복참여 | 본인·가구원의 참여·예정·수혜 이력을 확인한다. 이력이 있으면 기관이 확인한 가입 가능·제한 또는 확인 중으로 구분한다. |

자활기업·자활근로사업단 소득을 인정한다. 공공 일자리는 인건비 지원·별도 채용 등 예외를 확인할 수 있게 했다. 근로장학금·실업급여·육아휴직급여만 받거나 무급근로만 하는 경우를 일반 근로소득과 구분한다. 소득 증빙·대체 자료의 인정이 확인 중이면 0원이나 불충족으로 바꾸지 않는다.

가구원의 가입이나 과거 지원금 환수만으로 중복참여를 확정하지 않는다. 사치·향락·도박·사행성 업종 등 제외 대상, 신용정보·계좌 개설, 신청서·가구 조사·선정 심사는 별도로 남긴다. 확인한 조건이 모두 충족해도 전체 자격은 `NEEDS_REVIEW`다. 가입 후 유지·지급 조건은 추가 안내이며 이번 질문으로 판정하지 않는다.

## 연결과 변경 처리

`YouthTomorrowSavingsRules`의 규칙 버전은 `youth-tomorrow-savings-2026-v1`, 검토한 해시는 `f3709a60376cdaf861ee232c1fc411292f2d3bdcb28c807ca87190a19698733c`다. 목록·내 조건의 질문 표시는 기존 `ReviewedPolicyQuestions`를 통해 연결한다. 후속 코드 `5ab882d`에서 같은 출생일 비교를 [내 조건의 연령 결과와 정렬](condition-policy-discovery.md)에 연결했다. 상세 질문의 동작과 규칙 버전은 유지했다.

기존 질문·평가 DTO와 웹 폼을 재사용한다. 답변은 평가할 때만 보내며 저장하지 않는다. 정책 개정·내용 해시·규칙 버전이 바뀌면 이전 답변을 409로 거절한다. 서울 날짜로 2027년이 되면 질문·목록 필터에서 제외하고 새 모집 안내로 바꾼다. 2026년 접수 마감을 표시하되 마감 자체로 개인 조건을 불충족 처리하지 않는다.
