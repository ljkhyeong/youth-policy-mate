# 자격 조건 비교

제품 기준은 [PRD의 자격 안내](../../docs/PRD/0001_product-baseline/spec.md#5-자격-안내와-추천-근거)다. 변경할 정책의 원문·개정·예외와 사용자 입력의 의미를 먼저 확인한다.

## 판단 기준

- 조건 충족과 기관의 최종 자격 확정을 구분한다. 전체 결과에는 필요한 모든 조건을 반영하고, 미응답·원문 모순·해석 실패는 추가 확인 필요로 남긴다.
- 불충족을 바꿀 수 있는 예외가 미확인이라면 불충족으로 확정하지 않는다. AI 요약·추출 후보·신뢰도를 확정 규칙으로 사용하지 않는다.
- 연령은 해당 정책의 기준일·계산법으로 비교한다. 서비스 대상인 19~34세를 모든 정책에 적용하지 않는다.
- 지역은 전국·서울·자치구 및 원문이 인정한 생활권을 구분한다. 전국 정책을 누락하거나 지역 분류만으로 신청 가능 지역을 넓히지 않는다.
- 취업 상태의 정의·기준일, 소득의 개인/가구 구분·대상 기간·기준 연도·가구원 수·단위를 맞춘다. 기준이 없으면 추정하지 않는다.
- 모집 상태와 개인 자격을 별도로 계산한다. 정렬은 자격 상태·미확인 사유·근거를 바꾸지 않는다.
- 정책 개정·규칙 버전·사용자 입력·기준일을 식별하고 같은 값에는 같은 결과를 낸다. 시간 계산에는 주입한 `Clock`과 명시적인 시간대를 사용한다.
- 입력이나 정책이 바뀌면 이전 답변의 적용 가능 여부를 확인해 재판정한다. 결과에 사용한 조건·입력·원문 근거·사유를 보존한다. 단일 정책을 위해 범용 규칙 엔진을 만들지 않는다.

## 검증

- 변경한 규칙의 충족·불충족·미확인과 결과를 바꾸는 예외를 단위 테스트로 확인한다. 날짜 경계·윤년·소득 경계는 해당 규칙에 영향을 주는 사례만 추가한다.
- 직렬화·화면 연결이 바뀌면 대표 결과로 확인한다. 같은 규칙 사례를 API·화면 테스트에 반복하지 않는다.
